# Goaltje

Goaltje is een WK 2026 voetbalpoule-app gebouwd met React, Vite, TypeScript en Supabase.

## Scripts

- `npm run dev` start de lokale ontwikkelserver
- `npm run build` maakt een productiebuild
- `npm test` draait de tests
- `npm run lint` draait ESLint

## Structuur

- `src/` frontend app
- `public/` statische assets zoals icons en SEO-bestanden
- `supabase/` migraties en edge functions

## Opmerking

Controleer je environment variabelen en Supabase-configuratie voordat je lokaal deployt of edge functions draait.
